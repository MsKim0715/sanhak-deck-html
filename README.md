# 산학 프로젝트 · 인터랙티브 웹 프레젠테이션

`index.html` 을 Chrome / Edge / Safari 로 열고 **F** 키로 전체 화면 → 발표.
외부 라이브러리·CDN 없이 동작합니다 (폰트·이미지·영상 모두 폴더 안에 포함).

## 조작
| 입력 | 동작 |
|---|---|
| → · Space · PageDown · ↓ | 다음 장 |
| ← · PageUp · ↑ | 이전 장 |
| 마우스 휠 · 트랙패드 | 한 번 스크롤에 한 장 (관성은 무시) |
| 좌우 스와이프 | 다음 / 이전 장 (모바일) |
| 숫자 + Enter | 해당 장으로 이동 (예: 1 2 Enter → 12장) |
| G 또는 하단 번호 클릭 | 슬라이드 목록 열기 · 바로 이동 |
| 왼쪽 목차 항목 클릭 | 그 섹션의 첫 장으로 이동 (자기소개 2장 · 회사/직무 3장 · 프로젝트 5장 · 향후 계획 25장). Tab → Enter 로도 가능 |
| P 또는 하단 ❚❚ 버튼 | 애니메이션 정지 / 재개 |
| F | 전체 화면 |
| Home / End | 처음 / 마지막 장 |

주소 끝에 `#12` 를 붙이면 12장부터 열립니다. 새로고침해도 보던 장이 유지됩니다.
Ctrl+P → "PDF로 저장" 하면 한 장씩 PDF로 뽑힙니다 (배경 그래픽 체크).

## 구성
- 총 27장 = 내용 21장 + 챕터 전환 6장
- 챕터 전환 슬라이드는 프로젝트가 바뀌는 지점에 들어갑니다
  (테스트 자동화 → 데이터 분석 → 디스코드 서버봇 → study_rag → 모뉴먼트 밸리 → 언리얼 프로젝트).
  자동으로 넘어가지 않고, 다음 입력이 있을 때까지 멈춰 있습니다.
- 03 개요 장이 첫 프로젝트의 인트로 역할을 하고, 마지막 프로젝트 뒤에는 04 향후 계획으로 바로 이어집니다.

## 애니메이션
- 장 전환: 왼쪽 목차는 고정, 오른쪽 이미지·텍스트 영역만 움직임
  · 다음 장: 이전 내용이 왼쪽으로 빠지며 사라지고, 새 내용이 오른쪽에서 밀려 들어옴 (이전 장으로 가면 반대 방향)
  · 제자리 페이드만 원하면 js/deck.js CONFIG 의 `transition: 'fade'`
- 챕터 전환 장: 큰 번호가 아래에서 올라오고 → 제목 단어가 차례로 → 설명 → 아래 목차 막대가 채워짐.
  배경의 커다란 번호는 마우스 반대쪽으로 천천히 움직임
- 스크린샷: 마우스를 올리면 위치에 따라 살짝 3D로 기울고, 누르면 그 자리에서 화면 가득 커짐 (다시 누르거나 Esc 로 제자리)
  끄려면 CONFIG 의 `lightbox: false`, `tilt: false`
- 영상(피크민 맵): 영상을 누르거나 재생 막대 오른쪽 ⤢ 버튼을 누르면 화면 가득 커짐. 재생은 끊기지 않고, 커진 상태에서도 재생 · 탐색 막대를 그대로 씀
  · 커진 영상을 누르면 재생 / 일시정지 (Space 도 가능), 영상 바깥 · Esc · ⤡ 버튼으로 제자리. 커진 동안에는 장이 넘어가지 않음
  · 작은 상태의 재생 / 일시정지는 가운데 ▶ 버튼과 막대의 버튼으로
- 마우스를 따라다니는 은은한 주황 빛 (끄려면 `glow: false`)
- 슬라이드 상태: inactive → entering → active → exiting. 전환 중 입력은 한 번만 예약되고 나머지는 무시
- 표지: 사진이 살짝 줌아웃되며 드러나고, 마우스에 따라 아주 조금 움직임
- 03 개요: 타임라인 선이 왼쪽부터 그려지고, 선이 닿는 순서대로 PART 1 → 4 카드가 떠오르며 점과 이미지가 잠깐 빛난 뒤 멈춤
  (속도는 css/deck.css 의 --rm-start, --rm-step)
- 아키텍처 흐름:
  - 테스트 자동화 아키텍처 · 디스코드 서버봇 구조 · study_rag 구조
  - 다이어그램의 화살표를 읽어서, 데이터 패킷이 화살표 방향과 순서대로 이동하고 도착한 상자가 잠깐 빛납니다
  - 주황 = 호출 흐름, 베이지 점선 = 구현 · 위임 (디스코드 서버봇의 ports → 어댑터)
  - 장에 들어가면 시작, 나가면 멈추고 정리
  - 구조 개편 장(반복): 변경 전은 '홈 화면 UI 변경'이 로그인 상태별 페이지 → 테스트로 번져 '수정' 6곳 → 이어서 변경 후는 HomePage 한 곳만 '수정', 테스트 1개가 project로 guest · member 에 나눠 실행 (data-cycle 로 한 주기를 나눠 씀, 색은 --fail)
- 아키텍처 설명 장(아키텍처 · 구조 개편 · 서버봇 구조 · study_rag 구조와 처리 흐름)은 반복
- 데이터 분석 흐름만 한 번 재생하고 멈춤 (장에 다시 들어오면 다시 재생)
- 테스트 자동화 · 문제 2 장(9장): 요소 직접 참조 도식만 한 번 재생 — 테스트 A → B → C 순서로 각자 참조하는 요소에 닿고 멈춤 (`data-play="once"` + `data-sync="sources"`, 장에 다시 들어오면 다시 재생). nav바 도식은 정지
  · 한 번 재생으로 바꾸려면 다이어그램 div 또는 data-pipeline 묶음에 data-play="once"
- 움직임 줄이기 설정(prefers-reduced-motion)이나 P 키로 정지하면, 전환은 즉시 바뀌고 흐름은 정지된 경로만 보여 줍니다

## [초안] 다이어그램 탐색
- 아키텍처 장(테스트 자동화 아키텍처 · 디스코드 서버봇 구조 · study_rag 구조)에서
  상자를 누르면, 그 상자로 들어오는 앞단 흐름과 나가는 뒷단 흐름만 남고 나머지는 어두워집니다.
- 데이터 패킷도 고른 흐름 위로만 움직이고, 아래 안내 칩에 "○○ 기준 흐름 · 연결된 구성요소 n개"가 표시됩니다.
- 같은 상자를 다시 누르거나, 빈 곳을 누르거나, Esc 를 누르면 해제. 장을 넘기면 자동 해제.
- 키보드: Tab 으로 상자 선택 → Enter / Space
- 끄려면 js/deck.js CONFIG 의 `explore: false`

## 화면 크기
- 가로 화면(데스크톱·노트북·태블릿 가로): 1920×1080 무대를 화면에 맞춰 축소/확대
- 세로 화면·좁은 화면(태블릿 세로·모바일): 한 줄 흐름으로 재배치되고 장마다 세로 스크롤.
  다이어그램은 통째로 줄여서 보여 줍니다. 좌우 스와이프로 장 이동

## 파일
- `index.html` : 슬라이드 27장. `<section class="slide">` 한 블록 = 한 장 (주석에 번호·제목)
- `css/deck.css` : 색 변수(--accent 등), 전환 시간(--fade-in · --fade-out), 흐름·HUD·반응형 스타일
- `js/deck.js` : 상태 관리, 탐색, 흐름 애니메이션, 단계 하이라이트, 영상 (맨 위 CONFIG 에서 속도 조절)
- `assets/` : 이미지 · 영상 · 폰트

## 수정 팁
- 글자·배치: index.html 해당 section 의 텍스트나 style 수정
- 포인트 색: css/deck.css 맨 위 `--accent`
- 흐름 속도: js/deck.js CONFIG 의 `flowSpeed`, `flowRest`, `stepTime`
- 특정 다이어그램 흐름 끄기: 그 다이어그램 div 에 `data-flow="off"`
- 출발 상자별로 차례로 재생: 다이어그램 div 에 `data-sync="sources"` (위 상자의 화살표가 모두 도착한 뒤 다음 상자 출발)
- 단계 하이라이트 추가: 묶음에 `data-pipeline`, 각 칸에 `data-step`, 사이 화살표에 `data-step-arrow`
